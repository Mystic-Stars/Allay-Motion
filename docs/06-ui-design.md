# 06 界面设计

包：`packages/ui`（设计变量、shadcn 组件、编辑器专用控件）；页面在 `apps/desktop/src/renderer`。

## 6.1 设计原则

1. **默认流程只有三步：选模板、调参数、导出。** 进阶功能收在菜单和对话框里，不占主界面。
2. **现代的专业媒体工具。** 专业软件的骨架（多轨时间轴、时间码、精确数值、标签页、状态栏），现代的平面表面（留缝的圆角面板组、只靠灰阶分层、无描边、无压印、无发光）。依据见 `docs/design-direction.md`，视觉基准是定稿稿 `docs/design/ui-direction-v4.png`（源码 `ui-direction-v4.html`）。
3. **中性灰分层，强调色很少。** 底色、面板、次级面、凹槽、控件全是不带色相的灰，彼此只差几级亮度。天蓝强调色只用在：选中、焦点环、播放头、数值填充、激活的切换图标、导出按钮；全窗口只有“导出”一个实心强调色按钮。琥珀只表示“改过的参数”和剪辑点。
4. **所见即所得。** 任何参数变化都在下一帧反映到预览；预览和导出逐帧一致。
5. **安静的动效。** 小状态变化不超过 120 ms，只做亮度、透明度变化；尊重“减少动效”。骨架屏的形状与最终布局完全一致，内容出现时没有位移。

**明确禁止**：半透明的发丝描边（`border-white/10` 这类）、药丸形标签加状态小圆点、渐变、模糊、外发光、压印边、彩色左边条。阴影只用于真正浮起的东西（预览下方的悬浮工具条、弹层、菜单、对话框、通知、工具提示）。

**映射到 shadcn 的变量**：`--card` = `surface-1`，`--popover` = `surface-2`，`--muted`、`--secondary`、`--input` = `control`，`--accent` = `control-hi`，`--muted-foreground` = `fg-muted`，`--destructive` = `danger`，`--border` = `divider`，其余同名。

**与主题无关的变量**（`:root`）：字号、圆角、尺寸、密度、焦点环、动效，见下面几节。主题由少数输入决定：每套主题的颜色只在上面两块里；密度只改 `--density` 一个数（行高、控件高随之变）。

**字体**

- 应用界面、品牌文字和启动页用平台界面字体，简中与英文使用同一字体栈，缺字交给系统字体回退。代码、等宽数字与时间码用平台等宽字体，不随界面语言切换到另一套字体，不随应用分发字体。
- `--font-ui: system-ui, sans-serif`；`--font-num: ui-monospace, "SFMono-Regular", Consolas, monospace`。
- 授权的游戏字形只用于作品内容（模板画面、封面、导出及明确属于作品内容的字形样张），缺字逐字回退到系统字体；不用于产品界面和品牌。
- 所有数字（数值框、时间码、帧号、分辨率、时长、刻度、版本号）用等宽体加 `tabular-nums`（工具类 `num`）。
- 字号：正文与控件 12（`text-sm`），次要 11.5（`text-xs`），刻度 10.5（`text-2xs`），面板标签 12.5 半粗（`text-base`），模板名标题 15 半粗（`text-lg`），时间码 19（`text-xl`）。行距紧凑（1.3）。层级靠字号、字重和三级灰，不靠颜色。

**形状、层次、尺寸**

- 面板：圆角 10（`--r-panel`），彼此间距 6（`--gap`），无描边、无阴影，靠与底色的灰阶差分开。控件圆角 6（`--r-control`），缩略图与时间轴片段 7（`--r-tile`），分段控件里的选中块 5（`--r-inner`）。
- 顶栏 44、状态栏 24、面板标题行 40、时间轴面板 236；属性行高约 32（`--h-row`）、控件高 26（`--h-control`）。
- 浮起的东西用 `--shadow-float`（弹层、菜单、工具提示、通知、悬浮工具条）或 `--shadow-dialog`（对话框）。
- 焦点环：2 px 强调色，外偏移 2 px（6.9）。

**图标**：Phosphor（`@phosphor-icons/react`，MIT），不自绘。常态用 regular，激活、选中、播放控制用 fill。尺寸 12–16 px，常量集中在 `packages/ui/src/lib/icons.ts`（`ICON`、`ICON_WEIGHT`），应用根部用 `IconContext` 给默认值。

**动效**

```css
--dur-1: 80ms;    /* 悬停、按下 */
--dur-2: 120ms;   /* 弹层、开关、内容切换 */
--dur-4: 400ms;   /* 悦灵进出场 */
--ease-out: cubic-bezier(.2, .8, .2, 1);
--ease-in-out: cubic-bezier(.45, .05, .2, 1);
```

- 只做亮度、透明度变化；弹层和对话框淡入，不缩放。
- “减少动效”开启时（系统设置或应用内开关）：所有时长归零，悦灵和骨架不动。

**像素图的显示**：缩略图、方块图标一律 `image-rendering: pixelated`，按设备像素的整数倍缩放。透明棋盘格用两档低对比的中性灰（`--checker-a` / `--checker-b`）。

## 6.3 窗口与布局

- 无边框窗口：`titleBarStyle: 'hidden'` 加 `titleBarOverlay`（Windows 上保留系统的最小化、最大化、关闭按钮，颜色随主题更新为 `--background`）。标题栏、菜单栏和工具栏合成顶栏一条。
- 默认 1440×900，最小 1120×700，记住上次的位置和大小。
- 主区是一组留缝（6 px）的圆角面板，坐在底色上。分栏用 react-resizable-panels（外层 [主列 | 右栏]，主列里上面是 [左栏 | 预览]、下面是时间轴），宽度和折叠状态持久化。以后要停靠一个额外的面板，在分栏里多加一个面板即可；左右面板的标签页也可以再加一个。

## 6.4 各区域

**顶栏（44 px，直接坐在底色上，不是面板）**

- 左：悦灵头像（22 px）和字标；菜单“文件 / 编辑 / 视图 / 帮助”，条目都映射到已有的命令：
  - 文件：新建、打开、最近的工程、保存、另存为、导入模板；
  - 编辑：撤销、重做、换一个随机种子；
  - 视图：主题、语言、预览背景、安全框参考线、折叠左栏、命令面板；
  - 帮助：设置、快捷键、关于。
- 正中：工程名和“已修改”（有未保存的改动时）。
- 右：素材状态（最上层的图标和名称，点开是资源栈弹层）、撤销、重做、设置、“导出”分体按钮——主体打开导出对话框，右侧小段的下拉列出导出格式，选中后带着这个格式打开对话框。“导出”是全窗口唯一的实心强调色按钮。最右留出系统窗口按钮的位置。
- 空白处是窗口拖动区；所有可交互元素标 `no-drag`。

**左面板：模板库**

- 标题行（40 px）：标签页“模板 | 预设”（12.5 半粗，选中项正文色、其余第三级灰），右侧是搜索图标（展开搜索框，`Ctrl+F` 同）和导入图标。
- 模板页：分类“全部 / 转场 / 叠加 / 我的”是安静的文字切换，选中项有控件底色。两列缩略图（16:9，圆角 7），名称在下、时长（等宽，取 manifest 时间段的默认值之和；不知道时不显示）在右。悬停时播放预览循环；选中 = 面板色 2 px 间隙 + 2 px 强调色外框，名称变成正文色，不发光。用户自己的模板在角上有一个 `--amethyst` 的小点。
- 预设页：当前模板的预设列表（沿用已有的预设存取），点一下应用；属性面板里的预设下拉也保留。
- 图库可按标题分类，也可用中文名、英文名、标签或 ID 搜索全库。模板和工作台插入面板每页六项；默认「全部」保留原六张卡在首页。两个工作台技术模块沿用「叠加」与搜索中的图标条目。
- 当前页按需取 320×180 静帧；悬停或键盘聚焦才请求 30 fps 预览图集。离页释放封面，离开预览释放位图。资源或语言变更只重建仍在使用的项目，杂务 Worker 空闲时释放。重建期间显示骨架和悦灵。也可以把 `.allaytpl` 拖进窗口。
- `Ctrl+B` 折叠或展开左栏。

**中间：预览面板（`--viewer` 底色）**

- 左上“预览”和模板名，右上规格读数（等宽，如 `1920 × 1080 · 60 fps`）。
- 画布按输出比例等比缩放、居中，上面让出标题行（44 px）、下面让出工具条（60 px）、左右各 30 px。
- 预览工具是悬浮在画面下方居中的一条（真正浮起的东西，有阴影）：缩放（显示实际百分比，下拉里是“适应窗口 / 100%”）、背景（棋盘格、纯色、示例素材）、安全框参考线、高质量预览。纯色背景时多一个色块按钮。
- 示例素材模式在 `cutTime` 之前显示画面 A、之后显示画面 B；两张原创示意图尚未提供，这一项暂时禁用（decisions.md M4）。
- 引擎装载超过 180 ms 时，视口里出现悦灵的加载编排（见 `07-allay-mascot.md`）。
- 模板出错时，视口显示错误卡片（浮起的次级面）：一句说明、“重置参数”、“复制诊断信息”。

**时间轴面板（236 px，跨左、中两列）**

- 标题行 48 px：到开头、播放（32 px 的圆角方块按钮）、到结尾、循环（开着时是强调色）；大号时间码 `当前 / 总时长`（`分:秒:帧`，等宽 19 px）；右侧静音。
- 多轨：左侧 124 px 的轨道名列（阶段、音效、剪辑点，各带实心小图标），右侧轨道是凹槽圆角条。
  - 帧刻度（等宽数字，标签间隔按宽度自动取 1/2/3/5/6/10… 帧）；
  - 阶段轨：按 `timeline.segments` 画出进入/停留/退出三个圆角色块（`--stage-*`），带名称和时长（窄的色块只居中写名称），色块两端各一个小手柄；段与段之间的分界线可以拖动（见 `04-templates.md` 4.3）；
  - 音效轨：按模板装载结果里的 `audioCues` 画 `--cue` 竖条（只读）；没有 cue 的模板这一轨置灰；
  - 剪辑点轨：琥珀菱形加帧号；没有剪辑点的叠加层模板不显示这一轨。
- 播放头：1.5 px 强调色竖线贯穿各轨，顶部是带当前帧号的小牌；整个轨道区按下即可拖动（键盘：左右键逐帧、Shift 十帧、Home/End）。
- 不做磁吸和时间轴缩放（定稿图里画了，是新功能，不在这次范围内）。

**右面板（跨主区和时间轴两行高）**

- 标题行：标签页“属性 | 输出”，右侧更多菜单（保存为预设、另存为模板、重置全部参数、导入/导出预设）。
- 属性页：模板名（15 px 半粗）和“类别 · 时长”，右侧预设下拉；主体按 `groups` 分组，分组是标题行（实心小三角 + 半粗标题）加组间 1 px 分隔线，折叠状态按模板记忆；底部一行“另存为模板 / 全部重置”。
- 每一行：左标签（次要色，约 30% 宽，过长截断，悬停显示 `hint`）+ 右控件。改过的参数在标签左侧有一个琥珀小点，悬停这一行时它变成“重置”按钮。右键菜单：重置、复制值、粘贴值。
- 控件：
  - 数值框即滑块：一个控件，有范围的数值按比例用 `primary-soft` 填充底色，数值右对齐、等宽；拖动改值、单击或双击键入；

**文件夹**

- 工程默认保存文件夹：新工程“保存”“另存为”时对话框从这里开始，“打开工程”也从这里开始。
- 导出文件夹：M7 的 `export.folder`，导出的文件直接写在这里。
- 每行显示路径（凹槽底、可选中复制）、“选择…”、有值时一个清除按钮。路径只来自主进程的文件夹对话框；渲染进程只传 `project` / `export`（`folders.get / choose / reset`），主进程回给它的路径只用于显示（1.6 第 6 条）。

- 已记的文件夹现在不存在或不可写（例如移动硬盘没接）：设置里的值不动，这一行用警告色说明原因和退路——工程保存时对话框退回系统默认位置；导出时和没选过一样先弹文件夹对话框。窗口重新获得焦点时重查。

**快捷键**

- 列出注册表里能不带参数执行的命令（带参数的命令不能由按键触发；只给程序调用、不在命令面板里也没有默认快捷键的内部命令不列；只在一次性整页流程里有意义的命令——打开首次启动引导、打开新手引导——标了 `noShortcut`，不能有快捷键，也不列），按类别分组（播放、编辑、文件、视图、模板、导出、帮助、其他；命令的 `category`），每条带命令的 Phosphor 图标（`icon`）。顶部是搜索框（按名称、id、按键搜）和“全部恢复默认”。逐帧的方向键单列一行，不可改。
- 每行：图标、名称、右侧按键（`Kbd`，没有时写“未设置”）；悬停时出现清除按钮，改过的有恢复默认按钮，名称左边一个琥珀小点（琥珀只表示“已改动”）。
- 录制：点按键进入录制（强调色底和焦点环，“按下新的快捷键…”），按下的组合按物理键位记成 `Ctrl+Alt+Shift+键` 的写法；单独的修饰键不算；Esc 只取消录制，不关对话框；录制时按键不触发任何命令。
- 冲突：新键已被别的命令用着时，在这一行下面说明“{键} 已经给了‘{命令}’”，让用户选“替换”（那条命令的快捷键被清除）或“取消”。恢复默认时默认键已被占用的，那条命令被清除并发一条通知。
- 保留键不能绑定，行下用危险色说明原因：系统级（Alt+F4、Alt+Tab、Alt+Space、Ctrl+Esc、F11、F12 等）、文本输入必需（Ctrl+A/C/V/X、Backspace、Delete、Enter、Tab、Esc、Ctrl+左右方向键等）、逐帧和列表导航（不带修饰键或只带 Shift 的方向键）。完整的表在 `apps/desktop/src/shared/shortcuts.ts`。
- 自定义存在 `ui.shortcuts`（命令 id → 键，null 表示清除；等于默认值时不记）。渲染进程发来的整张表经 zod 校验（写法、保留键、条数）；读设置文件时坏掉的条目各自回到默认，整块坏了只回退这一项。手改设置文件造成两条命令同键时，排在前面的生效，两条都标警告。
- 菜单、命令面板、顶栏按钮的工具提示和全局按键处理都读生效的快捷键（默认值加自定义），执行一律经 dispatcher。

## 6.12 下载原版资源的进度

资源栈弹层、无素材引导、设置“素材”页和首次启动引导用同一个组件，引导里是大号、带悦灵的版本。

- 五个阶段，按顺序走，各有状态（等待 / 进行中 / 完成 / 失败 / 已取消，图标分别是空心圆、转圈、成功色对勾、危险色警告、减号）：
  1. 取版本清单（清单和版本 JSON）；
  2. 下载客户端 jar（显示已下载 / 大小）；
  3. 提取资源（下载资源索引，读出 jar 的条目目录；jar 整体保留，不解包）；
  4. 取常用音效（显示第几个 / 一共几个文件）；
  5. 建立资源索引（打开原版层、重建资源栈）。
- 整体进度按字节算：jar、资源索引、音效对象（已在缓存里且校验通过的文件算作已收到）。音效的总量要读到资源索引才知道，之前按“1 MB 与 jar 的 5% 中较小的”估计；分数只增不减。不是字节的几步各占一小份固定权重（清单 2%、读 jar 目录 3%、建立资源栈 5%），所以字节下完之后仍有推进，完成之前最多 99%，完成时 100%。
- 读数：已下载 / 总大小、速度（最近约 3 秒、只算真正从网络收到的字节）、剩余时间（超过 2 秒没有新数据就不显示这两项）、百分比（一位小数，等宽），以及一行“现在在做什么”（带版本号）。
- 取消、失败时进度留着：停下的那一步标成已取消 / 失败，写明“停在‘某一步’”和原因（网络、校验失败、磁盘写不进、未知），“重试”从头再走一遍（已下载且校验通过的文件不重下）。取消不留下载了一半的文件。
- 主进程的下载器逐个文件上报进度，经 zod 校验后交给 `DownloadTracker` 折算，节流 100 ms 经 `resources:changed` 推送；渲染进程收到的下载状态再过一遍 zod，不合法时只把下载这一块当空闲。白名单、哈希校验、“只由按钮触发”都不变（decisions.md M2a、M2b）。

## 6.14 新手引导

首次启动引导之后自动出现一次（`ui.tourCompleted` 为 false 时；新装为 false，已有设置文件的老用户读成 true，不被拉进来）。帮助菜单（“新手引导”）、设置“通用”页（“重新看一遍新手引导”）和命令面板里可以随时再看。

- 主界面整个压暗（`--tour-scrim`：深色 62%、浅色 42% 的黑），用 SVG 遮罩在要讲的区域开圆角 12 的口（区域四周留 6 px），口的边上一圈 2 px 强调色。一步可以开几个口，第一个是主区域。
- 吉祥物（72 px，`dialog` 优先级）和说话气泡（`surface-2`、对话框阴影、宽 380）停在主区域旁边空间最大的一侧（右、左、下、上，都放不下时放在区域里靠下），不出窗口。没有区域的一步放在正中。气泡里：标题、等宽的“3 / 9”、说明（几段）、进度点；底部“跳过引导”、“上一步”、“下一步”（实心强调色，最后一步是“开始创作”）。
- 键盘：焦点在“下一步”上；← → 翻页，Esc 跳过。主界面 inert，全局快捷键不穿透，“找到了你的 Minecraft”不弹。
- 换步时口和气泡移到新位置（320 ms 的位置和大小过渡），气泡弹出；减少动效时直接跳过去。
- 区域只用界面上已有的 `data-testid` 找；找不到或看不见的（左栏折起来了）这一步就放在正中。
