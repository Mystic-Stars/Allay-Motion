# 界面视觉方向（第四版，定稿）

用户在 2026-11-13 确认了这一版。视觉基准是定稿稿 `docs/design/ui-direction-v4.png`（1440×900 主界面）和它的源码 `docs/design/ui-direction-v4.html`：颜色、圆角、间距、字号的数值以源码里的 CSS 为准。稿子里预览画面的方块、模板缩略图是示意色块（实际由引擎渲染），悦灵头像是占位。实现落在 `docs/06-ui-design.md` 6.1–6.4，变量在 `packages/ui/src/styles/globals.css`。

此前的“方块工作台”（零圆角、缺角描边、斜面厚度、像素字、暖紫灰、方头图标）已经作废。

## 一句话

现代的专业媒体工具：**专业软件的骨架**（多轨时间轴、时间码、精确数值、标签页、状态栏），**现代的平面表面**（留缝的圆角面板组、只靠灰阶分层、无描边、无压印、无发光）。

## 要点

**颜色**

- 全部是不带色相的中性灰：底 `#0d0d0e`，面板 `#1a1a1b`，次级面 `#202021`，凹槽/轨道 `#131314`，控件 `#28282a`，控件高亮/选中 `#333336`，分隔线 `#262628`（只用于面板内部分组之间），预览面板 `#121213`。
- 文字三级：`#f0f0f1` / `#a2a2a6` / 第三级（稿子里是 `#6d6d72`，做文字时对比度不够，实现里提亮到 `#8b8b91`，原值只给图标）。
- 强调色天蓝 `#3cb7f4`，其上文字用深墨 `#04212f`；20% 透明版用于数值填充和选中底。只用在：选中、焦点环、播放头、数值填充、激活的切换图标、导出按钮。全窗口只有“导出”一个实心强调色按钮。
- 标记色琥珀 `#f2a93b`：只表示“改过的参数”小点和剪辑点。
- 时间轴阶段色：进入 `#2b6c9b`、停留 `#47474b`、退出 `#6652a6`；音效标记 `#49b382`。
- 浅色主题用同一套逻辑推导：中性浅灰分层，不用纯白大面积，不带色相；强调色换成在浅底上达标的更深的蓝。

**形状、层次、密度**

- 面板圆角 10，彼此间距 6，无描边、无阴影，靠与底色的灰阶差分开；控件圆角 6–7，片段与缩略图 6–7。
- 阴影只用于真正浮起的东西：预览下方的悬浮工具条、弹层、菜单、对话框、通知。
- 字号：正文与控件 12，次要 11–11.5，面板标签 12.5 半粗，模板名标题 15 半粗，时间码 19。行距紧凑；属性行高约 32、控件高 26；面板标题行 40；顶栏 44；状态栏 24。
- 动效 ≤ 120 ms，只做亮度、透明度变化；尊重“减少动效”。

**字体与图标**

- 品牌、菜单、首次启动引导和编辑器控件统一使用系统 UI 字体；代码使用系统原生等宽字体，时间码用等宽数字。游戏字形不用于品牌或控件。
- 图标用 Phosphor：常态 regular，激活、选中、播放控制用 fill，14–16 px。

**结构**

- 顶栏一条（不是面板）：头像与字标、菜单“文件 / 编辑 / 视图 / 帮助”、正中工程名与“已修改”、右侧素材状态、撤销、重做、设置、“导出”分体按钮。
- 左面板“模板 | 预设”；中间预览面板（左上标题、右上规格读数、画面下方悬浮工具条）；右面板“属性 | 输出”（跨两行高）；底部时间轴面板（跨左、中两列，多轨：阶段、音效、剪辑点，带帧刻度和播放头小牌）；最下面状态栏。
- 数值框即滑块；顺序、图案类的 enum 用图案小格选择器（manifest 的可选界面提示）。

**明确禁止**

半透明的发丝描边、药丸形标签加状态小圆点、渐变、模糊、外发光、压印边、彩色左边条。

**这次不做**（稿子里画了，但属于新功能）：时间轴的磁吸和缩放。
