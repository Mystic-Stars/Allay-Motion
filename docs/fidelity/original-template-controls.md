# 原创内置模板：控件契约核查

以下是编辑器的原创转场、角色动作和合成对象，不是游戏内原版动画。检查从 manifest 的默认值和 `visibleWhen` 追到 `setup`、`update(t)`、资源选择和音频提示。所有模板的 ID、版本、参数键、枚举值、范围和默认值均保留；隐藏控件不清除旧工程或预设中的值。

| 模板 | 发现、处理与有意保留的行为 |
| --- | --- |
| `block-wipe` | 原「平面」实际是正交、无面明暗，仍会用立方体和用户选的翻转，改名而不改旧画面。重叠为 1 时顺序与错落自然失去作用；此时形状和材质参数仍生效，补说明，不抹去设置。选中音乐才显示音乐音量。 |
| `block-fall` | 未发现坠落、炸开和缩回互相覆盖，列序仍控制入场，缩回顺序从入场派生。零回弹不再为回弹预留进度，落地声随落地推迟，补说明而不改节奏。选中音乐才显示音乐音量。 |
| `item-stinger` | 自定义图片优先时隐藏物品选择，清空图片后原物品仍在。找不到图片时发双语诊断并用原选物品，不再让缺图占位遮住它。按动画贴图单帧的比例取景；方块色带采样当前帧，不铺整张动画图集。无声音时隐藏音量。直线模式仍使用像素大小控制条纹宽度和间距，不隐藏。 |
| `pixel-dissolve` | 错落只进入扫过和径向的阈值，按模式显隐；边缘宽度为零时隐藏边缘色，但不丢值。方块填充补上当前动画帧 UV；普通色填充和默认图案不改。反向退出只反转阈值顺序。两种全屏转场的方块填充仍忽略贴图 alpha，以保证剪辑点整屏遮盖。 |
| `player-motion` | 站立共用动作，站立和跳跃都没有步伐晃动，隐藏对应无效控件。第三人称视野会补偿取景距离，并非纯缩放，保留控件并说明。皮肤缺失或尺寸不符时不画角色并发出诊断；使用独立的贴图实例保留原过滤效果，避免更改共享资源。旧式 64×32 皮肤仍使用宽臂。 |
| `studio-object` | 未发现类型切换时旧图、字、方块或声音抢占当前分支。文字将实际文案、字体、字号、颜色、阴影传给文字 API；音频只登记一个源起点 cue，由合成裁切。补说明：静态图片不播放贴图动画，音量须选择音频才有效。 |

两个方块模板按最终格子分配材质，选择材质布局不会改变入退场顺序。**只有一种有效材质**时，权重或布局不改变画面；有序布局按列表顺序，跳过零权重且忽略非零权重大小。空列表或全部为零由 SDK 恢复默认材质，这是覆盖率保底，不改为透明。放置／破坏声音共享音量和空间开关，音乐单独以 0 秒、自己的音量发 cue。

## 公共层边界

- `visibleWhen` 支持对单个参数做比较，也支持用 `all`／`any` 组合条件，但不对材质列表内部作去重或有效权重计数。「至少两种不同且非零权重的材质」因此用提示说明，不增加冗余字段或抹去值。皮肤库与手臂模型的联动仍由公共属性控件管理。
- `optionalTexture` 会在同一资源代缓存缺失；如果用户恢复同一引用的外部文件但资源代没变，模板不能主动重探。重新选择或资源层更新是否应该主动失效，由宿主统一处理。文件授权丢失、工程修复与声音实际可读性也归宿主，模板不接触本机路径。

## 验证

`tests/unit/T-TPL.control-contracts.test.ts` 用各模板实际 manifest 清洗参数、运行实际 `setup/update`，断言旋转实例矩阵、落地与音乐 cue、资源分支和宽高比、动画帧 UV、溶解阈值数组、角色镜头、文字与音量值。既有 `T-TPL.ordered-palettes` 覆盖加权随机和有序格子布局。这里的着色器证据是纹理／uniform 与公式，不等同于真实 GPU 像素、音频回读或对游戏画面的还原；默认像素基准和改参后的真实 GPU 由父任务复核。

本机验证：控件契约、有序材质、旧预设、角色动作及素材对象共 40 项通过，根 TypeScript 检查与定向 lint 通过。`T-DEV-3` 的全模板源码检查仍报范围外的加载模板调用未纳入生成声明的 Three.js 成员，本次不改公共声明或加载模板。
