# 代码工作室

- 从工作台的「代码」入口进入。内置模板先「复制后编辑」；也可以「新建空白动画」。读取和保存只面向本机已知用户脚本模板的 `template.js` 和 `manifest.json`。保存前在备用 Worker 验证当前帧；冲突、静态错误和试运行失败不切换预览。文件分别以临时文件改名替换，第二次改名失败时回滚第一次；这不是可以抵御进程崩溃的双文件事务。
- 「合成 JSON」编辑工程使用的 `CompositionSchema`，不改写原有的脚本。应用前用同一套合成 Worker 装载并试渲染。
- 「固化为 .allaytpl」是手动操作，使用已经应用的合成。包内只有版本化的 `composition.json`，含画布大小、合成数据、精确的脚本模板版本与内容哈希、勾选的参数和素材引用。不把包当作一个脚本片段，因此不能递归嵌套。暂不接受依赖版本范围的派生模板。
- 在「可复用合成」中导入、回读和实例化；普通脚本模板继续走原安装入口。换机后先装齐匹配的脚本模板，再重连所需的图片、皮肤和资源配置。固化包不包含脚本模板包、游戏文件、资源包或本机导入的二进制素材。脚本自行解析的其他素材仍由其所在模板及本机资源栈提供。
